# incloud releases

Release binaries for the incloud server agent and the incloud CLI.

- Each release is tagged with its version (for example `v1.0.0`).
- Every release lists a `SHA256SUMS` file. Installers check each download against it before running anything.
- The server agent runs on Linux (`amd64` and `arm64`). It is installed on incloud servers automatically.

The source code lives in the main incloud repository. This repository holds release files only.
